# ♟️ Chessino (v1.0 beta)

**Chessino** — это шахматная песочница с открытыми правилами, собственным языком описания механики фигур и встроенным ИИ-движком **MatDream**.

## 🔥 Главные фишки
* **Никаких ограничений:** играй без обязательной защиты от шаха и пата — побеждает тот, кто первым срубит короля соперника.
* **Свой язык формул:** меняй ходы любой фигуры прямо в JSON-конфигах (например, преврати обычную пешку `(2n, 1, hr')` в всемогущего ферзя `(NaN//\\//-|, NaN//\\//-|)`).
* **Пиксель-арт 32×32:** ламповая ретро-графика без лишних зависимостей (работает на чистом Python + Tkinter).
* **Движок MatDream:** встроенный бот, который анализирует битые поля, спасает фигуры из-под удара и подстраивается под твои кастомные правила.

## 🚀 Как запустить
1. Скачай архив с последней версией из раздела **Releases** справа.
2. Распакуй папку в любое удобное место.
3. Убедись, что установлен **Python 3.x**, и запусти файл `chessino_gui.py`.

## 🛠️ Структура файлов
* `chessino_gui.py` — графическая оболочка и движок **MatDream**.
* `setup.json` — стартовая расстановка фигур на доске.
* `pieces.json` — базовые формулы движения фигур.
* `custom_mode.json` — редактор своих правил и модификаций.
